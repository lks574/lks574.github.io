## 예시: 소셜 로그인 기능 명세 점검

### 입력

```
명세 문서: https://notion.so/project/social-login-spec
Figma: https://figma.com/file/xxxxx/social-login
컨텍스트: 모바일 앱 사용자를 위한 소셜 로그인(Google, Apple, Kakao) 기능 추가
```

### 출력 — Step 1 (작업 체크리스트)

```markdown
## 📋 작업 체크리스트

- [ ] 명세 문서 및 Figma 전체 검토
- [ ] 소셜 로그인 제공자(Google, Apple, Kakao) 각각의 플로우 정의 확인
- [ ] 토큰 발급 및 갱신 정책 명세 점검
- [ ] 신규 가입 vs 기존 계정 연동 처리 흐름 점검
- [ ] 에러 케이스(계정 충돌, 권한 거부 등) 정의 확인
- [ ] 사용자 확인 질문 정리
- [ ] 최종 Tech Spec 문서 작성 및 자기 검증
```

### 출력 — Step 3 (사용자 확인 질문)

```markdown
## ❓ 확인이 필요한 항목

1. 동일 이메일로 다른 소셜 계정 연동 시 계정 병합 처리를 어떻게 할까요?
2. 소셜 로그인 연동 해제 기능이 이번 범위에 포함되나요?
3. 로그인 세션 유효 기간과 리프레시 토큰 정책이 정의되어 있나요?
4. Apple 로그인의 경우 이메일 숨기기 옵션을 허용하나요?
```
