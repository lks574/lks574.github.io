## ⚡ React Native 실무 트러블슈팅 아카이브

실무에서 에러를 만나 해결할 때마다 **"1이슈 1노트"** 원칙으로 가볍게 기록해두는 공간입니다.

---

### 📋 최근 해결한 이슈 목록

| 날짜 | 이슈 키워드 | 한 줄 요약 | 노트 링크 |
| :--- | :--- | :--- | :--- |
| `2026-03-11` | Metro Cache | 코드 변경이나 새 패키지 미반영 시 캐시 리셋 | [[metro-cache-reset]] |

---

## ✍️ 새 트러블슈팅 노트 작성 규칙
1. `troubleshooting/` 폴더 안에 `이슈-핵심-단어.md` 파일을 생성합니다.
2. 아래 3단 구조로 간단히 10~20줄 내외로 작성합니다:
   - **증상 (Symptom)**: 에러 로그 및 발생 상황
   - **원인 (Cause)**: 왜 발생했는가?
   - **해결 (Solution)**: 명령어 또는 수정 코드
3. 해결 후 이 목차 테이블에 한 줄을 추가합니다.
