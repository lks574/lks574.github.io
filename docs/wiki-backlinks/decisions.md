# 결정 기록: wiki-backlinks

## D-001 역링크 해소 규칙을 라우트와 공유 모듈로 통일 — 2026-09-14

### 맥락과 제약 (Context)
- `[[이름]]`이 어느 노트를 가리키는지 정하는 규칙이 이미 두 곳에 있었다. 라우트(`src/pages/wiki/[...slug].astro`)의 경로 생성과 린트(`scripts/lint-glossary.mjs`)의 해소 검사다.
- 역링크는 세 번째 소비자다. 세 곳이 각자 규칙을 들고 있으면 언젠가 어긋나고, 어긋나면 "린트는 통과하는데 화면에서는 빠지는" 조용한 실패가 된다.

### 선택 (Decision)
1. `src/lib/wiki-links.ts`에 노트 인덱스, 해소 함수, 역링크 계산을 두고 라우트가 같은 인덱스로 경로를 만든다. 라우트에 있던 규칙은 삭제했다.
2. 인덱스와 역링크 맵은 프로세스당 한 번만 계산해 모든 페이지가 공유한다.
3. 린트는 CI에서 TypeScript 없이 돌아야 하므로 JS 사본을 유지한다. 두 구현의 불일치는 빌드 결과물 검사(AC-BL-006)로 잡는다.

### 버린 대안과 이유 (Alternatives)
- **라우트 안에서 역링크도 계산:** 페이지마다 전체 컬렉션을 다시 훑게 되어 O(N²)이고, 규칙이 라우트 파일에 갇혀 재사용이 안 된다.
- **린트도 TS 모듈을 import:** `astro:content`에 의존하는 모듈이라 Astro 밖에서 실행할 수 없다. 린트를 Astro 통합 테스트로 바꾸는 것은 이 기능 범위를 넘는다.
- **역링크를 마크다운에 미리 써 두기(사람 또는 에이전트가 갱신):** 목표 G2(수동 관리 0) 위반. 용어집 역링크 규칙에서 이미 단방향 부패를 겪었다.

### 결과 (Outcome)
- 61페이지 빌드 중앙값 452ms (기준 610ms 이하 유지). 역링크 있는 노트 50/50에 섹션 렌더링. 해소 실패 경고 0건.

### 🧭 얻은 원칙 & 관련 용어 (Lesson)
- **같은 규칙을 소비하는 곳이 셋 이상이면 규칙을 모듈로 뽑고, 뽑을 수 없는 사본은 결과물 검사로 묶는다.** → [[idempotency]]와 같은 "진실 원천" 문제의 빌드 타임 버전이다.
- 승격 후보: 아니오 (일반적인 원칙이라 용어집 🧭보다 리뷰 체크리스트 2.5 "공유 상태의 소유자 하나"에 이미 포함된다).

## D-002 위키 파일명을 소문자로 고정 — 2026-09-14

### 맥락과 제약 (Context)
- 역링크 계산이 `[[Multi-Agent-Orchestration]]`, `[[Index-MOC]]`를 해소하지 못한다는 경고를 냈다. 조사 결과 Astro glob 로더가 id를 소문자로 슬러그화하므로 페이지는 `/wiki/multi-agent-orchestration/`에 생성되는데, 링크는 대문자 경로를 가리켰다.
- 로컬(macOS)은 대소문자를 구분하지 않아 링크 검사가 통과했고, 프로덕션(GitHub Pages, Linux)에서는 404였다. 확인: 대문자 경로 404, 소문자 경로 200.

### 선택 (Decision)
1. 두 파일을 소문자 케밥 케이스로 개명하고 링크 7곳을 소문자로 고쳤다.
2. 린트의 id 계산을 Astro와 같게 소문자화하고, 대문자 파일명을 error로 추가했다. 픽스처 테스트 1건 추가.

### 버린 대안과 이유 (Alternatives)
- **해소 함수를 대소문자 무시로 만들기:** 역링크는 맞겨지지만 remark가 만드는 href는 여전히 대문자라 404가 남는다. 증상만 가린다.
- **`hrefTemplate`에서 소문자화:** 링크는 고쳐지지만 옵시디언 볼트 안의 파일명과 사이트 URL이 계속 다르고, 린트가 여전히 로컬 파일명 기준으로 판단한다. 소스가 둘로 남는다.

### 결과 (Outcome)
- 재빌드 후 해소 실패 0건. 프로덕션 확인은 배포 후 수행 (검증 예정: 푸시 직후 curl).

### 🧭 얻은 원칙 & 관련 용어 (Lesson)
- **검사가 통과하는 환경과 실행되는 환경의 파일 시스템 성질이 다르면, 검사는 실행 환경의 규칙으로 맞춘다.** macOS의 대소문자 무시는 CI 통과와 프로덕션 404를 동시에 만든다.
- 승격 후보: 예 (플랫폼 무관. `tools/web/`이 생기면 옮긴다. 지금은 여기 둔다).
