## AC-BL-001 위키 노트 하단에 역링크 섹션
- **Given** `tools/react-native/architecture` 노트를 `fabric`, `jsi`, `concurrency-vs-parallelism` 용어가 링크한다
- **When** `/wiki/tools/react-native/architecture/` 페이지를 빌드한다
- **Then** 본문 아래에 "이 노트를 참조하는 노트" 제목의 섹션이 있고 위 세 노트가 항목으로 있다
- 검증 방법: 빌드 결과물 HTML 검사 (`grep`)
- 관련: PRD 5.1-1

## AC-BL-002 용어 페이지의 두 경로에 동일 표시
- **Given** `rag` 용어를 `agentic-rag`, `context-window`가 링크한다
- **When** `/wiki/glossary/ai/rag/`와 `/wiki/rag/` 두 페이지를 빌드한다
- **Then** 두 페이지의 역링크 섹션 항목이 동일하다
- 검증 방법: 두 HTML의 역링크 섹션 텍스트 비교
- 관련: PRD 5.1-1

## AC-BL-003 항목 구성
- **Given** `idempotency` 용어를 `concurrency-vs-parallelism`(용어집·아키텍처)와 `tools/ios/background-video-upload-design`(설계 기록)이 링크한다
- **When** `idempotency` 페이지를 빌드한다
- **Then** 각 항목은 참조 노트의 `title`을 텍스트로, 그 노트의 정식 경로를 href로 가진다. 용어집 항목에는 카테고리 이름이 함께 표시된다
- 검증 방법: HTML의 `<a href>`와 텍스트 검사
- 관련: PRD 5.1-2

## AC-BL-004 들어오는 링크가 없는 노트
- **Given** 어떤 노트도 링크하지 않는 노트가 있다 (테스트용 임시 노트)
- **When** 그 페이지를 빌드한다
- **Then** 역링크 섹션 요소가 HTML에 존재하지 않는다 (빈 제목도 없음)
- 검증 방법: 임시 노트로 빌드 후 HTML 검사, 이후 삭제
- 관련: PRD 5.1-3

## AC-BL-005 중복과 자기 참조
- **Given** 노트 A가 노트 B를 두 번 링크하고, 노트 B가 자기 자신을 링크한다
- **When** B 페이지를 빌드한다
- **Then** A는 한 번만 나오고 B 자신은 나오지 않는다
- 검증 방법: 임시 노트로 빌드 후 HTML 검사
- 관련: PRD 5.1-4

## AC-BL-006 경로 표기 통합
- **Given** 노트 X가 `[[rag]]`로, 노트 Y가 `[[glossary/ai/rag]]`로 링크한다
- **When** `rag` 페이지를 빌드한다
- **Then** X와 Y 모두 역링크 목록에 있다
- 검증 방법: 임시 노트로 빌드 후 HTML 검사
- 관련: PRD 5.1-5

## AC-BL-007 코드 안의 링크 제외
- **Given** 트러블슈팅 허브 노트가 작성 규칙 설명에서 인라인 코드로 `[[slug]]`를 쓴다
- **When** 빌드한다
- **Then** `slug`라는 노트가 없어도 빌드가 성공하고, 어떤 노트의 역링크에도 그 허브가 코드 예시 때문에 잡히지 않는다
- 검증 방법: 빌드 성공 + 린트 통과
- 관련: PRD 5.1-6

## AC-BL-008 자동 갱신
- **Given** 어떤 노트에 새 `[[대상]]` 링크를 한 줄 추가한다
- **When** 다시 빌드한다
- **Then** 대상 노트의 역링크에 그 노트가 추가된다. 다른 파일을 손으로 고칠 필요가 없다
- 검증 방법: 임시 편집 → 빌드 → HTML 검사 → 되돌림
- 관련: PRD 5.1-7, 목표 G2

## AC-BL-009 해소되지 않는 링크
- **Given** 어떤 노트가 존재하지 않는 `[[없는노트]]`를 링크한다 (린트는 이를 error로 잡지만 빌드 자체는 별도)
- **When** 빌드한다
- **Then** 역링크 계산은 그 링크를 무시하고 빌드는 성공한다. 경고 한 줄만 로그에 남긴다
- 검증 방법: 임시 노트로 `astro build` 직접 실행 (린트 우회) 후 로그 확인
- 관련: PRD 7 리스크 1

## AC-BL-010 빌드 시간
- **Given** 현재 위키 25개 노트, 사이트 61페이지
- **When** `npm run build`를 3회 실행한다
- **Then** `astro build` 보고 시간의 중앙값이 1.0초 이하다
- 검증 방법: 빌드 로그
- 관련: PRD 목표 G3

## AC-BL-011 정렬
- **Given** 역링크가 설계 기록, 개념 노트, 용어집 항목에 걸쳐 있다
- **When** 페이지를 빌드한다
- **Then** 설계 기록(tools/) → 개념(concepts/) → 용어집 → 기타 순으로 묶이고, 같은 묶음 안에서는 제목 가나다순이다
- 검증 방법: HTML 항목 순서 검사
- 관련: PRD Q1 (사용자 확정 전까지 "제안" 상태)
